## 一、产品概述与核心定位

### 1.1 产品定位
**Curio** 是一款面向高中生的 AI 英语词汇沉浸式学习产品。借助 AI 动态生成与预制故事能力，将枯燥的高考背单词任务转化为个性化的沉浸式悬疑探案体验——**单词不是要背的清单，而是推动剧情发展的关键线索**。

### 1.2 效果声称边界
专注于 **Level A 词汇辨认**（阅读理解）与 **Level B 语境掌握**（完形填空/长难句），不盲目追求盲目刷词数量，而是让背过的词在真实复杂语境中“认得出、用得准”。

---

## 二、差异化定位与双利益方战略

### 2.1 双利益方设计落地
- **学生端（使用者）**：体验驱动。通过《苍澜迷雾》悬疑主线、叙事化 Streak 连击提醒与关键抉择产生自驱学习动力。
- **家长端（决策者/付费方）**：效果驱动。拒绝虚拟 Mock 数字，通过真实学习数据生成可直接分享至微信朋友圈的 **Canvas 成果海报**。

---

## 三、核心体验与词汇双轨制

### 3.1 词汇双轨制与高密度连载规格（v0.4 重大更新）
- **高密度连载规格**：每章实际嵌入 **15 个高考词汇**（替代原 6-8 词规格），大幅缩短 3500 词全覆盖周期。
- **双轨展示与控制**：
  - 🔴 **核心词（1-2个/章）**：在章节 70% 处触发关键抉择，承载核心语义判断。
  - 🟡 **语境词（13-14个/章）**：金色高亮，点击浮层提供音标、词性、中文释义、词族（Word Family）与近义辨析，不强制做题。

### 3.2 关键抉择与支线汇流
- 关键抉择的错误选项必须精准对应一种词义误解。
- 答错后触发 **100~150 字支线汇流叙事**，让学生在故事后果中无感纠错并自然汇回主线，后台将该词标记为需强化词汇。

## 四、版本功能规格 (P1 vs P2)

### 4.1 P1 阶段（当前收尾）

| 模块 | 规格要求 | 状态/更新点 |
|------|---------|------------|
| **账号体系** | **手机号登录 + JWT Token 本地持久化** | ⚠️ 新增P1必做：记住登录状态，刷新不丢数据 |
| **主线故事** | 《悬疑推理·苍澜迷雾》前10章（15词/章） | ✅ 10章已入库，P1补全 100~150 字支线汇流 |
| **故事偏好** | 6种偏好卡片收集，给予首发主线提示 | ✅ UI已支持，文案友好引导 |
| **前后端打通** | Zustand Store 强制与 Hono API 同步 | ⚠️ 关键P1补全：打通阅读记录与词汇交互 |
| **家长报告** | 真实数据对接 + **Canvas 海报长图导出** | ⚠️ 新增P1必做：支持生成微信分享长图 |

### 4.2 P2 阶段（下阶段 MVP 规划）
1. **离线 SM-2 预制 Patch 故事生成**：根据用户第 N 天学习节奏，AI 自动在基底章节中嵌入最多 5 个到期复现旧词。
2. **多题材故事扩展**：生成「科幻冒险」与「校园青春」两条全新主线。
3. **系统级外置通知**：微信服务号通知 / 浏览器 Web Push 主动提醒。

## 五、技术架构与前后端打通

### 5.1 数据模型 (Packages/db)
- `users` 表支持 `phone` 字段（唯一索引），记录登录持久化 Token。
- `vocab_library` 已导入 **3500 高考核心词**。
- `content_library` 存储 10 章高密度故事正文、核心抉择题目与支线叙事。

### 5.2 前后端 API 通信
`App.tsx` 与 `store.ts` 在登录、Onboarding 提交、章节完成及词汇点击时，全面对接 `apiClient.ts`，确保用户数据落盘至 SQLite 数据库。

## 六、AI 系统与遗忘曲线 (SM-2) 调度

### 6.1 离线预制 Patch 方案（v0.4 核心架构）
- **阶段一（P2 MVP）**：假设所有用户按 1章/天 进度推进。系统离线计算第 N 天需要复现的旧词，按优先级选取**最多 5 个复现词/章**，通过 AI 离线批量脚本将其以语境词形式自然织入（轻度 Patch）基底章节。
- **阶段二（P3）**：升级为基于单人 SM-2 动态记录的 AI 实时整章重写。

---

## 七、成功指标与三层 KPI 体系

1. **行为层（学生）**：真实连续 Streak 天数、词汇世界收录数（/3500）。
2. **理解层（产品）**：关键抉择首发正确率、真题语境迁移测试正确率。
3. **效果层（家长）**：阅读词汇激活数、对比基线诊断的进步幅度（%+）、海报分享率。
