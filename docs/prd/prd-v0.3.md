## 一、产品概述

### 1.1 产品定位

**Curio** 是一款面向高中生的 AI 英语词汇沉浸式学习产品。

> 借助 AI 动态生成能力，将枯燥的背单词任务转化为个性化的沉浸式故事体验——单词不是要背的清单，而是推动剧情发展的关键。

### 1.2 核心理念

```
传统产品解决的问题：如何让学生坚持刷单词
Curio 解决的问题：如何让单词在有意义的语境中真正活起来
```

### 1.3 Slogan

> **每个单词，都是一个世界的入口**

### 1.4 产品名称释义

**Curio**（奇珍异品）= Curiosity（好奇心）的缩写核心，寓意：
用好奇心驱动学习，让每一个词汇都成为值得探索的奇妙世界。

## 二、问题与机会

### 2.1 现状诊断

高中英语词汇学习是一个**持续存在的刚需痛点**：

- 高考英语词汇量要求约 **3500 个**（新课标 II 级）
- 高中生平均词汇留存率仅约 **30%**（艾宾浩斯遗忘曲线影响）
- 市面上主流产品（扇贝、百词斩、不背单词等）的核心交互模式在过去10年几乎没有本质改变

### 2.2 三层问题拆解

| 层次 | 真正的问题 | 传统产品的应对 | 根本缺陷 |
|------|-----------|--------------|---------|
| **认知层** | 单词是孤立符号，缺乏意义网络 | 提供例句、词根词缀 | 仍是被动消费，不产生连接 |
| **情绪层** | 重复 = 无聊，大脑主动抵抗记忆 | 贴卡通皮、加音效、积分 | 表面趣味化，底层仍是题海 |
| **动机层** | 看不到"真实使用英语"的场景 | 排行榜、连续打卡激励 | 外部激励短效，停用率高 |

### 2.3 AI 带来的结构性机会

| 传统产品能做的 | AI 让我们能做的 |
|--------------|----------------|
| 固定例句展示 | 实时生成个性化语境故事 |
| 预设题目库 | 动态生成与剧情绑定的测验 |
| 通用学习路径 | 基于遗忘曲线的个性化词汇调度 |
| 一次性内容消费 | 持续演化的故事世界 |

### 2.4 竞品分析关键结论（v0.2 新增）

基于对 Duolingo、不背单词、百词斩、扇贝单词、MeloLingua/Langua 的深度拆解：

| 决策 | 来源洞察 |
|------|---------|
| **Onboarding 先给价值再收信息** | Duolingo 新用户引导逻辑：先体验再配置 |
| **设计叙事化 Streak 作为留存保底锚** | Duolingo Streak 的本质是损失厌恶，而非内容吸引 |
| **P1 只做 1 个精品关键抉择/章** | 所有竞品教训：质量 > 数量 |
| **词汇本以"故事场景"为索引而非清单** | 不背单词词汇本的反面教材 |
| **词汇高亮不强迫查词，仅作信号触发器** | MeloLingua 查词打断叙事状态的教训 |

## 三、目标用户

### 3.1 MVP 阶段聚焦

| 维度 | 定义 |
|------|------|
| **学段** | 高中生（高一～高三） |
| **学科** | 英语词汇（高考词汇表范围） |
| **使用动机** | 主动自驱学习（非家长/老师强制驱动） |
| **使用场景** | 独自学习，不依赖社交/竞争激励 |
| **平台** | Web 端（MVP 阶段） |

### 3.2 核心用户画像

#### 画像 A：「焦虑型自驱者」小林（高二，16岁）

- **痛点**：高考压力大，明知要背单词，但每次打开刷词 App 10 分钟就失去兴趣
- **行为特征**：喜欢看悬疑小说/剧集，习惯睡前刷手机30分钟
- **对产品的期待**：背单词的时候能像追剧一样停不下来
- **使用 Curio 的场景**：睡前 15 分钟，独自沉浸阅读

#### 画像 B：「效率型目标导向者」陈同学（高三，17岁）

- **痛点**：词汇量够但阅读理解失分，单词在语境中认不出来
- **行为特征**：学习计划性强，关注英语成绩提升
- **对产品的期待**：词汇真正在语境中被掌握，不只是认识孤立的词
- **使用 Curio 的场景**：每天早读前10分钟，完成今日词汇故事

## 四、产品策略

### 4.1 核心设计原则

1. **效果第一**：学习效果是目标，沉浸感是手段，两者通过故事协同实现
2. **意义驱动**：词汇学习必须发生在有意义的语境中，绝不孤立记忆
3. **无感科学**：遗忘曲线等记忆科学在后台静默运行，用户毫无感知
4. **零挫败感**：没有"答错了"，只有"故事走向了不同方向"
5. **真实个性化**：基于兴趣的内容生成，而非表面的皮肤/主题切换

### 4.2 学习效果边界定义（v0.3 新增）

高考英语词汇能力的考察分三层，Curio 的效果声称边界如下：

| 能力层级 | 定义 | 对应考点 | Curio 覆盖 |
|---------|------|---------|----------|
| **Level A 词汇辨认** | 看到单词，知道大概意思 | 阅读理解（约40分）| ✅ 核心优势 |
| **Level B 语境掌握** | 在不同语境中准确理解词汇细微差异，能区分近义词 | 完形填空（约15分）| ✅ 通过多语境复现覆盖 |
| **Level C 主动输出** | 在写作中自主、准确地使用词汇 | 书面表达（约25分）| ❌ 需专项输出练习，MVP不覆盖 |

**Curio 的诚实定位**：

> 专注于 Level A + Level B——让背过的词在阅读中真正发挥作用。
> Curio 不是「让你多背500个词」的产品，
> 而是「让你背过的词在阅读理解中认得出、用得准」的产品。

**竞品对比中的核心论点**：
- 扇贝/不背单词解决「背了多少词」；Curio 解决「背过的词在复杂语境中能不能用」
- 百词斩解决「记住这个词」；Curio 解决「在阅读理解长难句中识别这个词」

**未来升级方向备注（P3+）**：随着产品成熟，将探索加入输出练习模块（造句、改写、仿写），支持 Level C 主动输出能力培养，迈向全面词汇掌握。

### 4.3 差异化定位矩阵（v0.3 轴更新）

> 注：v0.3 将旧轴「趣味性 vs 学习效果」替换为更精准的「词汇语境深度 vs 学习可持续性」。
> 旧轴过于模糊，竞品可轻易用「词汇数量/题型覆盖」反驳 Curio 的效果声称；
> 新轴直指 Curio 的真实差异化优势。

```
              词汇语境深度高
                    ↑
                    |
      Curio ★       |       不背单词
  （深度 + 可持续）  |   （深度但难坚持）
                    |
  <-----------------+------------------>
   可持续性高        |          可持续性低
                    |
      百词斩         |        扇贝单词
  （浅层但好玩）    |    （有深度但枯燥）
                    |
  多邻国（独立象限） |
  （高持续但无高考   ↓
   词汇对齐）  词汇语境深度低
```

**Curio 的核心主张**：
> 唯一在「深度理解词汇」和「让学生主动坚持」两个维度同时做到强的产品。
> 我们刻意不追求「每天接触词汇量最多」——
> 每天真正理解 5 个词，比每天背过 20 个词更有价值。

### 4.4 双利益方战略（v0.3 新增）

Curio 面对两个利益方，他们的决策逻辑完全不同：

| 利益方 | 角色 | 核心诉求 | 产品设计应对 |
|-------|------|---------|------------|
| **家长** | 决策者（付费/推荐）| 效果驱动：孩子英语阅读成绩有没有提升？| 学习效果报告（量化、可追踪）|
| **学生** | 使用者 | 体验驱动：有没有趣、能不能坚持下去 | 沉浸式故事体验 + 叙事化留存机制 |

**两者的闭环**：
```
家长看到效果数据 → 持续付费/推荐
        ↑
学生愿意持续使用 → 真实学习数据积累
        ↑
产品提供沉浸体验 → 学生主动坚持
```

### 4.5 核心壁垒

1. **个性化故事数据**：用户的兴趣偏好、阅读行为、词汇掌握数据，构成难以复制的个性化模型
2. **故事-词汇绑定机制**：将学习行为深度嵌入叙事体验，竞品难以在不重建核心体验的前提下模仿
3. **词汇语境记忆网络**：用户在 Curio 中建立的"词汇→故事场景"记忆网络，形成平台黏性

## 五、核心体验设计

### 5.1 核心学习循环

```
+-------------------------------------------------------------+
|                     CURIO 核心学习循环                       |
|                                                             |
|  ① Demo 体验（首次）                                         |
|     └─ 预置精品故事片段 + 关键抉择，先给价值                  |
|          ↓                                                  |
|  ② 兴趣校准                                                  |
|     └─ 用户选择故事类型偏好 + 学习强度档位                   |
|          ↓                                                  |
|  ③ 今日故事生成                                              |
|     └─ AI 基于兴趣偏好 + 今日词汇集 生成专属叙事             |
|          ↓                                                  |
|  ④ 沉浸阅读                                                  |
|     └─ 词汇按双轨分级出现：核心词高亮，语境词轻标注           |
|          ↓                                                  |
|  ⑤ 关键抉择（每章1个，在70%处触发）                          |
|     └─ 剧情节点出现选择题，测验核心词义理解                  |
|          ↓                                                  |
|  ⑥ 支线汇流（选错时）                                        |
|     └─ 故事向前延伸100~150字，自然呈现词义后汇入主线         |
|          ↓                                                  |
|  ⑦ 自然复现（间隔重复）                                      |
|     └─ 语境词在后续章节以不同语境反复出现                    |
|          ↓                                                  |
|  → 下一个 Session                                            |
+-------------------------------------------------------------+
```

### 5.2 Onboarding 完整流程（v0.3 更新）

#### 设计原则：先给价值，再收信息，最后建立基线

```
STAGE 0  欢迎页
         · 品牌印象建立，10秒浏览
         · 核心文案：Slogan + 3个核心特性 Badge
         · CTA：「先读一段故事 →」

STAGE 1  Demo 体验
         · 随机从 MVP 词汇表中抽取一套预置故事片段
         · 顶部标注：「🕵️ 悬疑推理 · 还有5种故事等你探索」
         · 200~250字精品叙事 + 词汇金色高亮
         · 在章节70%处触发1个关键抉择（支线汇流机制）
         · 完成抉择后过渡语：
           「这就是 Curio 的方式——
            每一个词，都藏在故事最关键的时刻。
            现在，让我们了解你的起点。」

STAGE 2  基线诊断（v0.3 新增，约3~5分钟）
         · 目的：建立词汇理解基线数据，用于后续效果对比
         · 形式：一段无高亮短文（约150字），测试5~8个高考核心词
         · 交互：读完短文后，针对其中词汇做3~5道语境理解题
         · 呈现方式：与故事阅读器体验一致，非传统测试感
         · 完成后显示：
           「你的阅读词汇激活水平：__（基础/进阶/优秀）
            接下来，Curio 会追踪你的进步轨迹。」
         · 数据用途：作为「学习效果报告」的起点对比基准

STAGE 3  偏好配置（单页）
         区域A：「你最喜欢哪类故事？」
                6个类型卡片，可多选
                每个卡片带一句氛围预览文案
         区域B：「你想要多深的挑战？」
                3档强度卡片（非滑块）：
                🌙 睡前放松  → 约5分钟 / 3个词
                📚 每日学习  → 约15分钟 / 5个词（默认）
                🔥 全力备考  → 约25分钟 / 8个词

STAGE 4  进入首页
         · 配置确认动效
         · 「正在为你生成专属故事……」过渡动画
         → Dashboard
```

### 5.3 词汇双轨制（v0.2 新增）

每章词汇按深度分为两级，采用不同强化路径：

```
+-----------------------------------------------------+
|  【核心词】1~2 个/章                                  |
|  → 承载关键抉择，触发深度语义编码                     |
|  → 这个词是这章「故事意义」的关键                     |
|  → 用户选错了会影响对故事走向的理解                   |
+-----------------------------------------------------+
|  【语境词】4~6 个/章                                  |
|  → 金色高亮，点击可查义（不强制）                     |
|  → 在本章自然出现，语境完整但不做测验                 |
|  → 遗忘曲线驱动：下一章或N天后以不同语境复现          |
+-----------------------------------------------------+

语境词升级机制（触发任一条件即升级为下章核心词）：
  · 用户点击查看了词义卡片（信号：不认识）
  · 该词已出现2次但用户从未点击（信号：可能跳过）
  · 上次关键抉择答错，且该词是关联词（信号：需强化）
```

### 5.4 关键抉择机制（升级版）（v0.2 重大修订）

> 这是 Curio 区别于所有现有产品的**核心差异化机制**，在竞品中属于未被占领的空白。

#### 触发位置

关键抉择在每章 **70%** 处触发，此时用户已建立足够的情感投入，但仍有阅读动力。

#### 设计标准

**标准1：用户在乎故事走向，不是词义测验**

差的设计（词义测验伪装成故事）：
> 林亦发现了一封 ambiguous 的信。请问 ambiguous 最接近哪个意思？

好的设计（故事决策内含词义验证）：
> 林亦必须现在做决定——
> A. 立刻锁定嫌疑人（信已经指向了明确目标）
> B. 继续收集证据（信含混不清，无法得出可靠结论）✓
> C. 忽略这封信，它只是烟雾弹

**标准2：错误选项必须「合理可信」**

每个错误选项对应一种具体的词义误解，而非明显错误的陷阱。

**标准3：每章只有 1 个关键抉择**

MVP 阶段固定为每章1个，保证叙事流畅度优先于词汇覆盖率。

#### 支线汇流模式（替代原「返回重选」设计）

```
用户做出错误选择
        ↓
  支线叙事（100~150字）
  ——故事自然推演错误选择的后果
  ——词义在后果中被「体验」，而非被「解释」
        ↓
  支线末尾：叙事自然汇入主线
  ——不是倒带，而是「走了弯路，但路还在延伸」
        ↓
  主线继续前进（不重复选择题）
  ——系统后台将该词标记为「需强化」
  ——在下一章中，该词从「语境词」升级为「核心词」
```

### 5.5 词汇三阶段曝光模型

```
第一阶段：【无感嵌入】
   词汇在叙事文本中自然出现
   点击可查义，但不强制
   目标：产生「这个词是什么意思？」的自发好奇心

           ↓  （当次或下一次阅读）

第二阶段：【主动验证】
   通过「关键抉择」验证核心词词义理解
   在做选择的过程中强化记忆编码
   目标：建立词义→故事情境的深度关联

           ↓  （间隔重复，遗忘曲线驱动）

第三阶段：【自然复现】
   词汇在后续故事中以不同语境再次出现
   学生感知到的是「这个词又出现了，我认识它！」
   目标：多维度语境构建，从认知到真正掌握
```

### 5.6 用户完整旅程（修订版）

#### 首次使用（Day 1）

```
打开 App
  → 欢迎页（10秒，品牌印象）
  → Demo 体验（200~250字故事片段 + 关键抉择，约3分钟）
  → 偏好配置单页（故事类型 + 学习强度，约30秒）
  → 首页 Dashboard
  → 进入第一章主线故事
  → 完成第一个关键抉择
  → 当天学习完成，词汇入库
```

#### 日常使用（Day 2+）

```
打开 App（通知唤醒 or 主动进入）
  → 首页 Dashboard
    （叙事化 Streak 状态 + 上章悬念引用句 + 今日故事入口）
  → 进入主线故事（新章节）
  → 沉浸阅读 + 关键抉择
  → 完成反馈 + 词汇入库
  → （可选）词汇本回顾
```

## 六、功能规格

### 6.1 功能清单与优先级（修订版）

#### P0（MVP 必须）

| 功能模块 | 功能点 | 说明 |
|---------|-------|------|

## 七、AI 系统设计

### 7.1 AI 能力需求

| 能力 | 详细说明 | 难度评估 |
|------|---------|---------|
| **故事生成** | 根据「故事类型 + 目标词汇列表 + 前情摘要」生成新章节 | 中 |
| **词汇无痕嵌入（Level 3）** | 先展示词义概念，再让词自然出现，达到「语义必然性嵌入」| 高 |
| **关键抉择生成** | 自动生成与词义深度关联的剧情选择题 + 支线汇流叙事 | 高 |
| **支线叙事生成** | 针对每个错误选项对应的词义误解，生成有针对性的支线 | 高 |
| **故事连续性维护** | 跨章节保持人物、世界观、情节的一致性 | 高 |
| **词汇调度** | 基于遗忘曲线和答题历史，决定今日核心词与语境词集合 | 中（算法）|

### 7.2 Prompt 策略（概要）

**故事生成 Prompt 核心要素：**

```
角色设定：你是一名专业的短篇故事创作者，
         擅长为中国高中生创作有代入感的【故事类型】题材故事

叙事风格要求：
- 段落长度3~5句，节奏明快
- 每150~200字设置一个小悬念钩子
- 对话占20~30%，简短有力
- 结尾必须开启新问题

词汇嵌入要求：
- 【语境词列表】：在叙事中自然出现，做金色高亮标注
- 【核心词】：必须先用2~4句叙事展示词义概念，
             再让词汇在情感节点出现（Level 3 嵌入）
- 核心词必须在章节70%处前完成嵌入，为关键抉择铺垫

其他约束：
- 前情摘要：[上一章内容摘要]
- 主角：林亦 Elena Lin（16岁，华裔，父亲失踪三年）
- 世界观：苍澜市（海滨城市，有历史谜题积淀）
- 本章字数约 800 字
- 本章需在结尾留有悬念

输出格式：
- 正文（纯叙事）
- 词汇位置标注（用于前端高亮）
- 关键抉择题目 + 正确选项 + 3个干扰项（各对应一种词义误解）
- 各选项对应的支线叙事（100~150字，针对具体误解）
- 本章摘要（用于下一章的 Prompt 前情）
```

### 7.3 词汇调度算法（MVP 简化版）

```
词汇状态分类：
  - 未接触：首次出现
  - 语境词：在故事中高亮出现，用户未做关键抉择
  - 核心词-已测验：
    → 答对：计入「已掌握」，按遗忘曲线安排复现
    → 答错：词汇标记「需强化」，下章升级为核心词

语境词升级触发条件（任一）：
  1. 用户点击查看了词义卡片
  2. 该词已出现2次，用户从未点击
  3. 上次关键抉择答错，且该词是关联词

复现间隔（简化 SM-2 算法）：
  第一次答对 → 1天后复现
  第二次答对 → 3天后复现
  第三次答对 → 7天后复现
  第四次答对 → 21天后复现
```

## 八、故事圣经（v0.2 新增）

### 8.1 内容策略：IP 风格克隆 + 同人创作

Curio 不借用任何现有 IP 的角色、情节、世界观，但深度研究面向青少年的悬疑冒险类流行 IP（如猫小九系列）的叙事基因，将其提炼为创作规范，应用于100%原创故事内容。

**长期策略**：P3 阶段在产品验证后，主动与优质 IP 方洽谈正式授权合作。

### 8.2 叙事基因规范

| 元素 | 规范 |
|------|------|
| **段落长度** | 3~5句/段，不超过8句，视觉上「轻」|
| **悬念密度** | 每150~200字出现一个小悬念钩子 |
| **对话比例** | 占全章20~30%，每句对话不超过两行 |
| **章末设计** | 最后一句必须是开放性问题或强视觉画面 |
| **情感调性** | 严肃中有轻盈，主角内心独白可以有少年感 |

### 8.3 世界观设定

```
城市：「苍澜市」（虚构，海滨城市，有百年历史积淀）
时代：当代
氛围：现实主义 + 历史谜题叠加

核心谜题（贯穿主线的深层背景）：
  三年前，苍澜市发生了一系列未解失踪案
  林亦的父亲是最后一个调查该案件的警探
  案件未结，父亲失联
  林亦以「普通高中生」的身份，在不被察觉的情况下继续追查
```

### 8.4 角色设定

#### 主角：林亦 Elena Lin

| 维度 | 设定 |
|------|------|
| **全名** | 林亦 Elena Lin |
| **年龄** | 16岁，高三 |
| **外在身份** | 苍澜市第一高中学生，成绩优异 |
| **隐藏身份** | 失踪警探林海之女，在暗中调查父亲消失的真相 |
| **核心能力** | 对语言和措辞高度敏感，拥有近乎完美的细节记忆力 |
| **性格缺陷** | 过度相信自己的判断，有时在「看见自己想看见的」上犯错 |
| **驱动力** | 找到父亲，而非抽象的「主持正义」|

> **词汇学习设计价值**：Elena 对语言高度敏感这个设定，让「分析措辞」成为她破案的天然工具。词汇在故事中扮演的不只是学习内容，而是推理的线索。

#### 配角：陈顾

| 维度 | 设定 |
|------|------|
| **年龄** | 17岁，Elena 的同班同学 |
| **身份** | 市警察局局长之子 |
| **功能** | 代表「体制内规则」与 Elena「规则外直觉」的叙事张力来源 |
| **关系** | 对 Elena 的调查既协助又阻拦，动机复杂 |

### 8.5 词汇嵌入三级质量标准

| 等级 | 描述 |
|------|------|
| **Level 1（禁止）** | 词义直接在括号或旁白中解释 |
| **Level 2（合格）** | 词在真实语境中出现，意思可推断 |
| **Level 3（要求）** | 先展示概念，词在情感节点出现，产生「就是这个词」的共鸣 |

**Level 3 示例（词汇：concealed）：**

```
Elena 仔细检查了房间里的每一个角落。
那幅画挂得太正了——正到不自然。
她把画框小心翼翼地从墙上取下，
指尖触到了一个折叠的信封。
有人花了很大力气让它消失在这个房间里。

那封 concealed 的信，等待了整整三年。
```

**四条嵌入规则：**

1. **先展示，后命名**：词出现前，用2~4句叙事描述词所代表的概念
2. **词必须在情感节点出现**：段末/章节转折处，情绪张力最高时
3. **词由行动呈现，而非旁白描述**
4. **核心词在同章出现2次，分别承担不同叙事功能**

### 8.6 关键抉择选项设计规则

每个错误选项必须对应一种具体的词义误解，支线叙事针对该误解有所回应。

**示例（核心词：deduce）：**

| 选项 | 内容 | 对应词义误解 |
|------|------|------------|
| A（错误）| 相信目击者陈述，立刻锁定嫌疑人 | 把 deduce 理解为「直接相信单一来源」|
| B（正确）| 综合所有线索，推断出最可能的时间线 | 正确理解：基于证据的系统性推理 |
| C（错误）| 证据不足，放弃这条线索 | 把「推断不确定」理解为「无法推断」|
| D（错误）| 等待更多证据出现 | 把 deduce 误解为「被动等待事实浮现」|

### 8.7 P1 两套 Demo 内容规划

#### Demo A（核心词：concealed）

| 维度 | 内容 |
|------|------|
| **场景** | Elena 在父亲的旧办公室里发现了一封被刻意藏起来的信 |
| **核心冲突** | 这封信是父亲故意留下的，还是有人伪造来误导她？|
| **关键抉择** | Elena 是否应该根据这封信的内容立刻行动？|
| **叙事基调** | 细腻、悬疑、有轻度情感底色（对父亲的思念）|

#### Demo B（核心词：deduce）

| 维度 | 内容 |
|------|------|
| **场景** | 案发现场，Elena 面对三个可能的时间线，两个证人陈述互相矛盾 |
| **核心冲突** | 必须在时间压力下推断出真正的作案时间 |
| **关键抉择** | Elena 选择用哪种推理方式处理矛盾的证词？|
| **叙事基调** | 快节奏、逻辑张力强、智识快感 |

## 九、留存机制设计（v0.2 新增）

### 9.1 留存五锚模型

```
Curio 留存 =
  叙事化 Streak（习惯锚）         → 解决「忘了来」
  × 故事悬念 + 叙事化通知（情感锚） → 解决「不想来」
  × Elena 寄生社交效应（关系锚）   → 解决「不在乎来不来」
  × 词汇成长可感知（成就锚）       → 解决「不知道来有没有用」
  × 回访前10秒体验（摩擦锚）      → 解决「来了但没立刻进入状态」
```

**P1 主锚**：叙事化 Streak（习惯锚）  
**P1 副锚**：故事悬念（情感锚）  
P2 接入真实 AI 后，两锚权重趋于平衡。

### 9.2 叙事化 Streak 设计

**核心原则**：不说「打卡」，只说「故事」

| 场景 | 文案 |
|------|------|
| **正常状态** | 「🕵️ Elena 正在等你 · 你已连续探索故事世界 X 天 · ❝ [上章末尾悬念句] ❞」|
| **缺席1天** | 「🌙 故事暂停了一天。Elena 在昨晚等了很久，但案件还在，线索还在。现在还不算太晚。」|
| **缺席2天（Streak归零）** | 「📖 你离开了 2 天。没关系。好的故事，随时都可以继续。Elena 把那封信保存好了，等你回来。」|

### 9.3 叙事化通知文案模板

| 场景 | 文案 |
|------|------|
| **Day 1→2（冷启动）** | 「Elena 在案发现场发现了第二条线索——这次，她需要你来推理。」|
| **Day 3+（熟悉期）** | 「🕵️ 昨晚留下的那个问题……她还没有答案。你呢？」|
| **缺席召回** | 「Elena 把那封信折好放进了口袋，等你准备好，她随时在。」|
| **连续7天里程碑** | 「你已经和 Elena 并肩推理了整整一周。今天，案件迎来了转折点。」|

### 9.4 词汇本作为成就锚

```
页头文案：
「我的词汇世界 · 你已收录 X 个词汇 · 它们都活在你的故事里」

每张词汇卡片包含：
  单词（金色大字）+ 音标 + 释义
  ❝ 来自故事的原文引用（斜体）❞
  📍 第X章 · [场景名称]
```

用户翻开词汇本看到的不是单词表，而是一段段与故事绑定的记忆。

### 9.5 回访前10秒体验设计

| 状态 | Dashboard 设计 |
|------|--------------|
| **Streak 完整** | 叙事化 Streak 卡置顶；上章最后一句话以引用体动态显示 |
| **Streak 中断** | 温柔召回文案置顶；减少内疚感，不施压 |

## 十一、成功指标（v0.3 全面重构为三层 KPI 体系）

> **设计原则**：三层 KPI 服务不同利益方——行为层让学生有成就感，理解层让产品知道真实掌握情况，效果层让家长看到可量化进步。

### 11.1 第一层：行为指标（学生可见，驱动持续投入）

| 指标 | 定义 | 呈现方式 |
|------|------|--------|
| **连续学习天数** | 叙事化 Streak | 「和 Elena 并肩探索第 X 天」|
| **词汇世界规模** | 已收录词汇数 | 「你的词汇世界已收录 X 个词汇」|
| **章节完成数** | 已解锁故事章节数 | 「已解锁 X 个故事章节」|

### 11.2 第二层：理解深度指标（产品内部，指导算法调度）

| 指标 | 定义 | 用途 |
|------|------|------|
| **关键抉择正确率** | 词汇在叙事语境中理解深度的直接度量 | 区别于传统「选词卡对错」，衡量语义决策能力 |
| **词义保留率（1/7/30天）** | 同词汇在后续章节新语境中复现时的关键抉择正确率 | 直接模拟高考「在新语境中识别熟词」场景 |
| **词汇点击率** | 语境词被主动查义的比例 | 低点击+答对=真掌握；高点击+答错=立即复现 |

### 11.3 第三层：效果指标（家长可见，驱动付费决策）

| 指标 | 定义 | 目标值（P2）|
|------|------|------------|
| **阅读词汇激活数** | 能在真实阅读语境中准确理解的高考核心词汇数 | 月均新增 ≥ 30 词 |
| **语境迁移正确率** | 已学词汇在全新故事语境中的理解正确率 | ≥ 65%（30天）|
| **高考词汇覆盖进度** | 已覆盖高考核心词汇 X/3500 | 可追踪的宏观进度 |
| **基线提升幅度** | 对比 Onboarding 基线诊断的进步百分比 | ≥ +20%（学习30天）|

### 11.4 P1 原型验证指标（用户测试专用）

| 假设 | 指标 | 目标阈值 |
|------|------|----------|
| Demo 体验触发真实兴趣 | Demo 完成率 | ≥ 75% |
| 学生愿意读故事 | 主线章节阅读完成率 | ≥ 60% |
| 关键抉择产生真实思考 | 选择前停顿时间 | ≥ 5 秒 |
| 词汇在语境中更易记忆 | 次日词义回想测试得分 | 对比传统方法 +20% |
| 学生愿意回访 | 「我想明天继续」意向调研 | ≥ 70% 表示是 |
| **家长认可效果** | 家长看完报告页面后的认可度调研 | ≥ 60% 表示「会让孩子用」|

### 11.5 竞品 KPI 对比矩阵

| KPI 维度 | 百词斩 | 扇贝 | 不背单词 | **Curio** |
|---------|-------|------|---------|----------|

| 词汇语境深度 | ★ | ★★★ | ★★★ | **★★★★★** |
| 词义30天保留率 | ★★ | ★★★ | ★★★ | **★★★★** |
| 阅读语境迁移 | ★ | ★★ | ★★ | **★★★★★** |
| 学习可持续性 | ★★★★ | ★★ | ★★ | **★★★★** |
| 家长可见学习报告 | ★★ | ★★ | ★ | **★★★★★** |
| 高考词汇对齐 | ★★★★★ | ★★★★★ | ★★★★★ | **★★★★★** |

## 十二、风险与应对

| 风险 | 可能性 | 影响 | 应对策略 |
|------|--------|------|---------|
| **AI 生成故事质量不稳定** | 高 | 高 | 建立 Level 3 嵌入质检标准；初期人工辅助生成 |
| **词汇嵌入生硬，破坏沉浸感** | 中 | 高 | 精调 Prompt；Level 3 标准强制执行；用户反馈机制 |
| **关键抉择选项质量差，不产生真实思考** | 中 | 高 | 每个错误选项对应明确词义误解；内测阶段人工审核 |
| **故事风格不受青少年欢迎** | 中 | 高 | 深度研究流行 IP 叙事基因；P1 用户测试结果快速迭代 |
| **学生觉得「太轻松」，担心无效** | 中 | 中 | 词汇本展示科学记忆进度；学习报告让效果可见 |
| **故事连续性在 AI 生成时丢失** | 中 | 中 | 前情摘要机制；世界观 Bible 作为 Prompt 约束 |
| **高中生时间有限，使用场景窄** | 低 | 中 | P2 的每日短篇补充碎片化场景；支持断点续读 |
| **LLM API 成本过高** | 中 | 中 | 选择性缓存 + 批量生成；商业化后再做规模化 |

## 十三、未来路线图

```
Phase 0（完成）：产品文档 v0.3 + 竞品分析 + 故事圣经
     ↓
Phase 1（P1）：Web 原型 + 用户测试（5~10名高中生）
              重点验证：沉浸阅读体验 + 关键抉择机制 + 家长效果报告认可度
     ↓
Phase 2（P2）：接入真实 AI + 完整词汇系统 + 用户账号 + 每日短篇
              新增：家长学习效果报告（量化）+ 完整三层 KPI 追踪
     ↓
Phase 3（扩展）：IP 联名合作洽谈 + 移动端 App（iOS 优先）
              新增：词汇语境迁移测试（模拟高考阅读题型）
     ↓
Phase 4（全面词汇掌握）：加入输出练习模块（造句/改写/仿写）
              实现 Level C 主动输出能力培养，迈向全面词汇掌握
              注：此阶段将「阅读理解专项」扩展至「全面高考英语词汇能力」
     ↓
Phase 5（拓展场景）：初中英语 / 高中语文文言文 / 高中历史
     ↓
Phase 6（商业化）：付费订阅（家长端）+ 学校端 / 老师端
```

### 长期愿景

> Curio 不是一个「背单词 App」，
> 而是**「把任何枯燥的学习任务都趣味化」的 AI 教育平台**。
> 英语词汇只是起点，好奇心才是终点。
