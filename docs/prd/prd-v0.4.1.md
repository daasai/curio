# Curio PRD — 产品需求文档

> **版本**：v0.4.1  
> **状态**：评审修订版·待冻结  
> **日期**：2026-07-29  
> **阶段**：P1 受控试点收尾 & P2 学习闭环 MVP  
> **替代关系**：本版本替代 v0.4；v0.4 保留为历史记录  
> **修订目标**：收敛产品假设，校正认证、指标、章节进度、15 词容量及固定间隔复现的声称边界。

---

## 一、结论与产品定位

### 1.1 产品定位

**Curio 是一款面向高中生的英语词汇沉浸式学习产品。**

它将高考词汇嵌入连续悬疑故事，并在剧情关键节点用「关键抉择」检验词义理解。Curio 不以刷词数量为核心价值，而是尝试解决两个问题：

1. 学生是否愿意持续完成词汇阅读；
2. 学生能否在新的阅读语境中再次认出并区分学过的词。

产品承诺限定在：

- **Level A 词汇辨认**：看到词时能够识别主要含义；
- **Level B 语境掌握**：能够结合上下文区分相近含义。

P1/P2 不声称能够系统提升 Level C 主动写作能力，也不在没有独立前后测证据时声称“提分”或“真实进步”。

### 1.2 P1 唯一核心假设

> 与普通词表学习相比，「连续悬疑故事 + 关键抉择 + 支线纠偏」能让目标学生更愿意持续完成学习，并产生可观察的语义理解信号。

P1 的研发和测试都应围绕这个假设展开。多题材、主动推送、实时生成和商业化包装不能挤占该闭环的完成度。

## 二、目标用户与使用场景

### 2.1 P1 目标用户

- 高一至高三学生；
- 有高考词汇学习需求；
- 对传统刷词模式容易厌倦；
- 愿意每天投入约 10–15 分钟完成一章；
- P1 仅招募 5–10 名受控测试用户，不作为公开商业服务。

### 2.2 双利益方

- **学生是使用者**：需要沉浸、连续、低打断的学习体验。
- **家长是关注者**：需要看懂真实发生过的学习行为，但不能看到未经验证的“提分”“领先同省”等结论。

P1 不建立独立家长账号。家长报告由学生端本地查看或导出图片；家长远程访问、亲子绑定与授权留待后续版本。

## 三、核心学习闭环

### 3.1 首次体验

1. 学生先体验一段故事和关键抉择；
2. 完成 4–10 道独立基线诊断题；
3. 选择故事偏好和学习强度；
4. 使用受控试点账号保存进度；
5. 进入《苍澜迷雾》第一章。

故事偏好在 P1 只用于收集需求，不改变首发内容。选择非悬疑题材时，应明确告知 P1 仅提供《苍澜迷雾》。

### 3.2 每章学习流程

```text
恢复进度
  → 按顺序进入下一章
  → 阅读并按需查看语境词
  → 正文结构约 70% 处触发关键抉择
  → 正确：叙事肯定
  → 错误：进入对应误解的支线汇流
  → 所有路径进入一次近义词辨析任务
  → 完成章节并保存学习快照
  → 返回首页
```

这里的“70%”是**正文结构位置**，不是用户滚动百分比。

### 3.3 词汇双轨制与总容量

每章实际嵌入词汇总数固定为 **15 个**，所有角色合计不得超过 15：

```text
15 = 1–2 个核心词 + 8–14 个新语境词 + 0–5 个复现词
```

- **核心词**：承载关键抉择；必须显式标记，不能通过数组顺序推断。
- **新语境词**：首次在故事中自然出现；点击后可查看释义。
- **复现词**：此前章节已经出现，本章再次进入新语境；属于语境词的一部分。

当复现词数量增加时，新语境词数量相应减少。因此，3500 词覆盖周期会随复现强度变化，产品不得继续以“约 240 章完成覆盖”作为固定承诺。

### 3.4 词汇浮层

P1 必须提供：

- 单词；
- 音标；
- 词性；
- 中文释义；
- 当前故事原句；
- 词族；
- 必要时提供近义辨析。

真人发音不属于 P1 必做项。若后续加入，需单独定义音频来源、授权、缓存、失败降级和英美音数据字段。

点击词汇表示“主动查阅”，不能等同于“已经掌握 Level A+B”。

### 3.5 关键抉择与支线汇流

关键抉择必须满足：

- 不知道核心词义时，不能仅靠情节常识答对；
- 知道词义但没有理解故事时，也不能脱离语境直接答对；
- 每个错误选项对应一种明确、可解释的词义误解；
- 每个错误选项都有自己对应的 100–150 字支线汇流；
- 支线用故事后果呈现词义差异，结尾自然回到主线。

关键抉择首答后不重选，以保留真实首答信号。支线结束后，所有用户都进入一次“近义词辨析任务”。该任务允许重试一次；它属于 Level B 语义检索，不称为 Level C 拼写输出。

### 3.6 章节顺序

P1 只允许按《苍澜迷雾》第 1–10 章顺序推进：

- 未完成当前章时，下次进入应恢复当前章；
- 已完成章节可以回看，但回看不重复增加完成章数或 Streak；
- 同一章节的重复完成请求必须幂等；
- 词汇匹配不能改变主线章节顺序。

## 四、版本范围

### 4.1 P1：受控试点收尾

#### P1 必做

1. **受控试点身份**
   - 通过测试管理员发放的手机号与一次性试点凭证登录；
   - 首次登录后设置测试 PIN；
   - 服务端签发安全会话，前端不信任或自行指定 `userId`；
   - 该方案仅用于 5–10 人受控试点，不包装成正式手机号认证。

2. **单主线完整体验**
   - 《苍澜迷雾》10 章；
   - 每章约 600–900 中文字，以阅读时长和叙事完整度共同验收；
   - 每章总计 15 词；
   - 1 个关键抉择；
   - 每个错误选项都有独立支线；
   - 所有内容通过词义、英语、叙事和未成年人适宜性检查。

3. **可靠学习进度**
   - 登录、Onboarding、章节恢复、词汇查阅、关键抉择和章节完成均写入服务端；
   - 网络失败必须可见、可重试；
   - 重复提交不能重复记数；
   - 日期按 Asia/Shanghai 计算。

4. **诚实家长报告**
   - 展示有效学习天数、完成章节、查阅词汇数、核心词首答正确率；
   - 独立迁移测验样本不足时显示“数据积累中”；
   - 不展示模拟数据、默认正确率、同省排名或未经验证的进步幅度；
   - 支持导出本地 PNG 长图，不承诺生成公开分享链接。

5. **基础观测**
   - 记录 Onboarding 完成、章节开始、章节完成、词汇查阅、关键抉择首答、支线完成、辨析任务结果和海报导出事件。

#### P1 不做

- 正式短信 OTP 与公开注册；
- 独立家长账号和亲子绑定；
- 实时 LLM 个性化生成；
- 科幻、校园等第二题材；
- 微信服务号或浏览器主动推送；
- “提分”“领先百分位”等效果声称。

### 4.2 P2：学习闭环 MVP

P2 的目标不是扩充功能数量，而是验证延迟复现和跨语境辨认。

#### P2 必做

1. **固定间隔语境复现**
   - 按章节位置预制复现词；
   - 每章最多 5 个复现词；
   - 所有用户共享内容版本；
   - 明确称为固定间隔复现，不称为个体 SM-2。

2. **独立迁移测验**
   - 使用未在故事中出现过的句子；
   - 基线与延迟测验使用等值题组；
   - 单独计算迁移正确率，不与故事内关键抉择混算；
   - 记录题组版本、样本数和测试时间。

3. **内容版本与质量门禁**
   - 基底章节和 Patch 章节均不可原地覆盖；
   - 每次生成形成新版本；
   - 通过自动规则和人工抽检后才能发布。

#### P2 条件项

- 第二题材必须由 P1 偏好数据和访谈共同决定，不预先锁定题材；
- 主动推送必须在 D7 留存与召回问题得到验证后立项；
- 正式手机号 OTP、家长访问及公开分享链接需另立隐私与认证规格。

### 4.3 P3 以后

- 按个人学习状态选择不同预制变体；
- 经成本和质量验证后，探索实时个性化内容；
- Level C 造句、改写和写作训练；
- 正式商业化账号、亲子关系与通知体系。

## 五、成功指标与声称边界

### 5.1 P1 北极星指标

**7 日有效学习留存率**：首次完成一章的学生中，第 7 日窗口仍完成至少一章的比例。

P1 样本只有 5–10 人，该指标只用于方向判断，不形成总体市场结论。

### 5.2 指标字典

| 指标 | 定义 | 不代表什么 |
|---|---|---|
| 有效学习天数 | 当天至少完成一章的上海自然日数量 | 打开 App 次数 |
| 完成章节数 | 去重后的首次完成章节数 | 阅读会话总数 |
| 查阅词汇数 | 主动打开过浮层的去重词数 | 已掌握词数 |
| 核心词首答正确率 | 关键抉择首次提交正确数 / 有效首次提交数 | 真题迁移正确率 |
| 辨析任务正确率 | 近义词辨析最终及首答结果 | 写作能力 |
| 独立迁移正确率 | 未见句子中的迁移题正确数 / 有效题数 | 故事内答题正确率 |
| 基线变化 | 等值前后测结果之差，并显示样本数 | 高考分数提升 |
| 海报导出率 | 导出用户数 / 有报告资格用户数 | 实际朋友圈分享率 |

### 5.3 P1 试点决策门槛

以下是试点 Go/No-Go 信号，不是统计意义上的产品结论：

- 10 章内容质量门禁通过率 100%；
- 受控测试期间无不可恢复的数据丢失；
- 至少 80% 测试用户完成 Onboarding 与第一章；
- 至少 60% 测试用户在 7 日内完成 4 章；
- 用户访谈中能复述关键抉择的词义差异，而非只记得剧情；
- 家长报告不存在模拟数字或无法解释的指标。

## 六、内容验收标准

每章发布前必须同时通过：

1. **结构**：600–900 中文字、15 词总预算、核心词显式标记、关键抉择位于正文结构约 70%；
2. **词义**：15 个词的词性、释义和上下文用法正确；
3. **抉择**：正确项唯一，每个错误项对应真实误区；
4. **支线**：每个错误项均有 100–150 字专属支线并汇回主线；
5. **叙事**：人物、时间线、线索和上一章连续；
6. **教学**：核心词满足“词义 + 语境”双重判断，不能靠常识猜中；
7. **安全**：适合未成年人，无过度暴力、羞辱、歧视或不当诱导；
8. **版本**：生成提示词、模型、内容哈希、审核人和发布时间可追溯。

当前数据库中的 10 章只视为“结构样稿”，完成上述门禁后才可改为“P1 可测内容”。

## 七、风险与应对

| 风险 | 应对 |
|---|---|
| 15 词导致认知过载 | 只测 1–2 个核心词；通过阅读完成率、查词率和访谈判断密度是否需要下调 |
| 故事吸引但学习无效 | 增加未见句子的独立迁移测验，故事内答题不作为迁移证据 |
| 固定复现被误解为个性化 | 对内外统一使用“固定间隔复现”，个体调度能力另行验收 |
| 乐观更新造成数据丢失 | 服务端为事实源，幂等写入、显式失败和重试队列 |
| 家长报告诱发过度声称 | 使用指标字典；样本不足显示“数据积累中”；禁止默认值和排名 |
| 未成年人账号与报告泄露 | P1 采用受控试点账号；不建立公开分享链接；正式发布前另做隐私评审 |
