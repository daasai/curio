## 待改进与退出条件

- IP HTTP 试点仅限受邀测试；完成 HTTPS 域名部署后，设置 `NODE_ENV=production`、`ALLOW_HTTP_COOKIES=false`、最小化 `ALLOWED_ORIGINS`。
- 服务器当前仍允许 root 密码 SSH，且登录失败次数异常高；改用密钥登录、关闭密码认证、限制 SSH 来源并审查日志。
- 部署脚本应验证 Bun 版本和 frozen lockfile 后才重载 PM2；失败时必须中止，不得继续执行后续步骤。
- 本次公网 HTTP 连通性会受网络出口限制影响；交付前需从独立网络再次确认 IP、端口与安全组可达，不将单次本机 health 请求失败误判为服务已停止。
- 为 Onboarding 保存、刷新恢复、首页/报告指标一致性和内容支线长度补充公网部署后的冒烟测试。
