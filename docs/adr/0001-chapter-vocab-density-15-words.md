# 每章词汇密度从6-8词升级为15词

PRD v0.3 原始规格为每章含核心词1-2个、语境词4-6个（共约6-8词）。在实际内容生成阶段，决定将每章词汇密度提升至15词，已在 `content_library` 中落地（10章×15词）。

这一调整是为了加速高考3500词的覆盖进度——按6-8词/章需要400+章才能覆盖所有词汇，而15词/章仅需约240章。代价是单章内词汇密度更高，需要前端在展示上明确区分「今日核心词（触发关键抉择）」和「故事语境词（高亮展示，不测验）」，避免认知负荷过重。

## Considered Options

- **保持6-8词/章**：叙事流畅，但3500词覆盖周期过长，用户需连续使用数年才能全覆盖
- **15词/章（已选）**：提高覆盖效率，前端通过双轨制视觉区分降低认知压力
