# ADR-0007：v0.5.0 安全加固与旧路由下线

**状态：Accepted**  
**日期：2026-08-10**

## 决策

移除所有由客户端 `userId` 直接授权的旧 API。业务接口统一从已验证的 HttpOnly 会话取得用户身份；登录失败计数改由数据库持久化；生产环境强制随机会话密钥、HTTPS Cookie 与 CORS 来源白名单。

## 后果

旧版 `/api/users/setup`、`/api/reading/session`、`/api/vocab/*`、`/api/schedule/daily`、`/api/user/*` 与旧家长报告接口不再可用。前端改用 `/api/learning/*`、`/api/report/*` 和新的 `/api/learning/onboarding`。这是一项有意的破坏性收口，避免旧入口成为绕过会话校验的旁路。
