# 双利益方设计：家长端真实数据海报与系统级推送分阶段落地

在 PRD v0.3 中定义的双利益方（学生+家长）战略，在 P1 及 P2 的具体功能落地方案如下：

## 决策内容

1. **家长端数据真实化（P1 必做）**：
   - 彻底废除家长报告中的 Mock 数据，全面对接后端 `/api/report/parent` 接口，展示真实阅读词汇激活数、真题迁移正确率及 Diagnostic 基线提升幅度。
   - 实现 **Canvas / HTML 导图功能**（海报导出）：点击「生成分享图片/链接」时，前端直接生成可直接保存/分享至微信朋友圈的学习进展海报长图。

2. **系统外置推送机制（P2 落地）**：
   - 学生端的叙事化 Streak 召回文案在 P1 仅作用于应用内 Dashboard 呈现（根据最后活跃时间动态渲染召回语）。
   - 微信服务号通知 / 浏览器 Web Push 等系统级主动触达通知能力，留待 P2 商业化与服务号搭建阶段接入。
