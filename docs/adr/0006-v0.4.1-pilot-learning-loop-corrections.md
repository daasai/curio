# v0.4.1 受控试点学习闭环修正

> **状态**：Accepted  
> **日期**：2026-07-29  
> **关联文档**：`docs/prd/prd-v0.4.1.md`、`docs/spec/spec-p1-completion-and-p2-mvp-v0.4.1.md`

## Context

PRD v0.4 与原 Spec 已明确 Curio 的高密度故事、关键抉择、家长报告和离线内容方向，但交叉评审发现六类会导致返工或错误声称的问题：

1. 故事内正确率被命名为真题迁移正确率；
2. 手机号标识、无短信验证和 JWT 登录被混为正式认证；
3. 所有人共享的离线章节被称为个体 SM-2；
4. 15 个新词与最多 5 个复现词的容量关系未定义；
5. 词汇匹配优先于连续章节进度；
6. 前端异步写入没有幂等、失败恢复和服务端事实源规则。

## Decision

### 1. P1 定义为受控试点

P1 只服务 5–10 名受邀测试用户。使用管理员发放的试点凭证完成首次激活，再以手机号和测试 PIN 登录。该实现不作为正式公开手机号认证；正式发布必须使用 OTP 或等价的可验证凭证。

所有学习接口从服务端会话读取用户身份，不接受客户端提供的 `userId`。

### 2. 每章采用 15 词总预算

核心词、新语境词和复现词的去重总数必须等于 15。复现词最多 5 个，并占用新语境词名额，不额外叠加。

### 3. P2 使用固定间隔语境复现

所有用户共享由章节序号决定的复现内容，因此 P2 不再使用“个体 SM-2”命名。只有当系统能根据个人状态选择不同内容版本时，才能声称个体化调度。

本决策覆盖 ADR-0002 中“阶段一可离线精确推算个人 SM-2”的表述，但保留离线预制、最多 5 个复现词和内容质量优先的方向。

### 4. 学习进度优先于词汇匹配

用户始终进入当前主线的下一章或恢复未完成章节。词汇调度只能在该章节允许的内容版本内选择，不能跳章或重复推荐已完成章节。

### 5. 服务端作为学习事实源

学习会话模块负责恢复、开始、记录事件和完成章节。所有写入使用幂等键；章节首次完成去重；前端必须呈现失败并支持重试。

### 6. 家长报告只展示可证明指标

故事内首答正确率、近义词辨析和独立迁移测验分别统计。无有效样本时返回空值，不提供默认正确率。查阅词汇不得命名为掌握词汇；P1 不提供排名、提分预测或公开分享链接。

## Supersedes

- ADR-0002：覆盖“阶段一属于个体 SM-2”的命名与解释；
- ADR-0003：覆盖“手机号 + 本地 Token 即构成 P1 正式登录”的实现；
- ADR-0004：收窄为真实数据本地海报，公开链接和远程家长访问不属于 P1。

ADR-0001 的 15 词方向和 ADR-0005 的单主线方向继续有效。

## Consequences

- 需要数据库迁移、受控身份模块、连续章节进度和幂等学习会话；
- 当前 10 章作为结构样稿保留，补全后以新版本发布，不原地覆盖；
- P2 对外文案必须使用“固定间隔语境复现”；
- 家长报告可能在早期显示“数据积累中”，这是诚实度要求，不是缺陷；
- 多题材和主动推送后置，直到 P1 留存与学习信号得到验证。
