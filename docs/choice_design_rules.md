# Curio 关键抉择设计规则
> 版本：v1.0 · 2026-07-15
> 来源：资深英语教师 × 产品经理圆桌讨论结论

---

## 核心原则：词义充要条件

> **关键抉择的正确选项，必须同时满足：**
> - ✅ 知道目标词义 + 读懂了故事 → 能答对
> - ❌ 读懂了故事但不知词义 → 不能仅凭叙事逻辑答对
> - ❌ 知道词义但没读故事 → 答题有障碍（不能脱离语境）

**违反此原则的典型反模式：**

| 反模式 | 示例 | 问题 |
|--------|------|------|
| 主角光环型 | 「谁的判断更接近真相？」 | 学生选主角，绕开词义 |
| 情绪共鸣型 | 「Elena 为什么感到害怕？」 | 靠情节推断，不测词义 |
| 常识替代型 | 选项仅凭生活常识可区分 | 词汇知识非必要 |

---

## ✅ 推荐题型：推论型抉择（Implication Test）

**模板**：「如果 [目标词] 的含义是 Y，以下哪个推论必须成立？」

**特点**：
- 选项描述的是词义的**逻辑结果**，而非人物对错
- 必须理解词义才能判断哪个推论符合
- 叙事知识作为语境辅助，但不能替代词义理解

**已实施示例（ambiguous，第一章）**：

> Elena 确认这封信是 ambiguous 的——她的下一步推理，必须建立在以下哪个前提之上？
>
> - A. 父亲当时匆忙，没有时间仔细选词（误区：vague ≠ ambiguous）
> - B. 写信人刻意设计了两条截然相反的路径，两条路都完整自洽 ✓
> - C. 两种读法都指向虚假线索，父亲在故意误导（误区：ambiguous ≠ misleading）
> - D. 既然两种解读都可能成立，这封信毫无价值（误区：ambiguous ≠ inconclusive）

## 干扰项设计规则

每个错误选项应对应一个**真实存在的词义误区**，而非随机错误。

| 干扰项类型 | 说明 | 示例 |
|-----------|------|------|
| 近义混淆型 | 目标词的真实近义词 | ambiguous → vague（最高价值干扰项） |
| 范围混淆型 | 上位词或下位词 | ambiguous → unclear（过宽泛） |
| 语义漂移型 | 在此语境下貌似合理的曲解 | ambiguous → misleading |
| 逻辑反转型 | 把「模糊」等同于「无效」 | ambiguous → inconclusive |

**原则**：选择了干扰项的学生，应该能从反馈中得到精准的词义区分说明，而不是泛泛的「你错了」。

## 输出信号收集器设计规则

| 规则 | 说明 |
|------|------|
| 不预填正确答案 | 预填 = 零认知参与；必须留空，学生主动选择 |
| 不设自动确认 | 自动确认 = 逃避思考；必须手动提交 |
| 确认按钮初始禁用 | 强制在选择后才能提交，防止空白提交 |
| 错选后精准定位反馈 | 说明选错的词与正确词在哪个维度不同 |
| 允许重试一次 | 自我修正过程比直接给答案记忆效果强 40% |
| 第二次错选后给记忆锚 | ambiguous / vague / unclear 三词对比表格 |

## PR 自查清单（AI 生成内容质检）

在生成或审核新章节的关键抉择前，必须确认：

- [ ] **词义充要性**：是否存在不理解目标词汇、仅凭叙事逻辑也能选对的路径？
- [ ] **干扰项覆盖**：每个错误选项是否对应一个真实的词义误区？
- [ ] **选项轴检查**：选项的分歧轴是词义推论，还是人物立场 / 情绪判断？
- [ ] **反馈精准性**：错误反馈是否指向具体的词义混淆点，而非泛化的否定？
- [ ] **输出信号**：输出信号收集器是否为空白强制选择？是否有针对近义词的精准纠错？

## 理论依据

- **构念效度**（Construct Validity）：测量工具应测量它声称测量的内容。关键抉择声称测「词义理解」，就不能被「叙事理解」替代。
- **矫正性反馈**（Lyster & Ranta）：精准定位错误维度的纠错，比直接给出正确答案的长期记忆效果高约 40%。
- **深度加工理论**（Levels of Processing）：选择 → 失败 → 自我修正的过程，是比被动接受更高级的认知加工层次。
